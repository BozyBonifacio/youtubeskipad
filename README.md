# YouTube Auto-Skip

A Chrome / Edge Manifest V3 extension that automatically clicks the YouTube Skip Ad button when it becomes available.

## Install on Chrome

1. Extract the ZIP.
2. Visit `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the extracted `youtube-auto-skip` folder (the folder containing `manifest.json`).
6. Reload any already-open YouTube tabs.

## Install on Microsoft Edge

1. Extract the ZIP.
2. Visit `edge://extensions`.
3. Turn on **Developer mode** / **Allow extensions from other stores** if required for your Edge version.
4. Click **Load unpacked**.
5. Select the extracted `youtube-auto-skip` folder.
6. Reload any already-open YouTube tabs.

## Use

Click the extension icon to enable or disable automatic skipping. The setting persists across browser restarts.

## Notes

- Only skips ads when YouTube presents a clickable Skip Ad button.
- Does not bypass unskippable ads.
- YouTube may change its player markup; selectors may require updating.
- No data is sent to any server.
